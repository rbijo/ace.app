# ACE Backend

The `backend/` directory contains the server-side API application, business logic, and database integrations for ACE.

## Planned Responsibilities

- **API Services**: REST/GraphQL endpoints for student data, tasks, and timetable operations.
- **Authentication**: JWT/Session handling, role management, and access controls.
- **Syllabus Processing**: Document ingestion, text extraction, OCR fallback, and structured data generation.
- **Agent Orchestrator**: Controlled execution of AI planning tools, study plan generators, and adaptive scheduling updates.
- **Database Persistence**: Integration with PostgreSQL database models and migrations.
