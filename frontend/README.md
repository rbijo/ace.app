# ACE Frontend

The `frontend/` directory contains the client-side user interface for the ACE application.

## Planned Responsibilities

- **Student Dashboard**: Overview of tasks, upcoming study sessions, and progress metrics.
- **Authentication**: Login, signup, and profile management screens.
- **Timetable Interface**: Interactive calendar and weekly timetable visualizer.
- **Syllabus Upload & Processing**: UI for uploading syllabus documents (PDFs) and reviewing extracted topics.
- **Task Management**: Interface to view, edit, complete, and prioritize generated study tasks.
