# ACE Shared Directory

The `shared/` directory contains code, type definitions, and configurations shared across frontend and backend environments.

## Planned Contents

- **Types & Interfaces**: Shared TypeScript or schema definitions for student models, tasks, timetables, and syllabi.
- **Validation Schemas**: Shared data validation schemas (e.g., Zod, JSON Schema).
- **Constants**: Shared application constants, error codes, and configuration options.
