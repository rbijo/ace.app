## About

ACE is an AI-powered education companion designed to assist students with academic tasks, syllabus processing, timetable management, study planning, and dynamically adapting schedules based on ongoing progress.

## Current Development State

**Status:** Planning / Foundation

ACE is currently in the initial structural foundation and setup phase. Core subsystems are being developed according to the project's planned backlog.

## Development Workflow

ACE follows a GitHub-based collaborative development workflow:

```text
Issue
  ↓
Branch
  ↓
Development
  ↓
Testing
  ↓
Pull Request
  ↓
Review
  ↓
Merge
```

### Pull Requests

ACE does **not** use a Pull Request template.

Contributors are free to explain their implementation, design decisions, testing, screenshots, and other relevant details in their own way.

### Issue Templates

Issue templates are used to maintain consistency when creating new issues.

>[!TIP]
> You can also use `Blank Issue` if you feel the template is not upto mark
