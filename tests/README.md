# ACE Testing Suite

The `tests/` directory houses global test suites, integration tests, E2E tests, and test utility fixtures.

## Planned Categories

- **Integration Tests**: Service-to-service and API integration tests.
- **End-to-End Tests**: Complete user journey verification (browser/UI to database).
- **Fixtures & Mocks**: Shared mock data for syllabi, timetables, and AI response evaluations.
